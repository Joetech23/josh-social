# Joshua · faceless video scripts · November 2026

16 scripts for the plan in [`2026-11-video-plan.md`](2026-11-video-plan.md). Pace: about 3 words a
second, so 100 words ≈ 33 seconds. **VO** = voiceover, **Screen** = what moves on screen.
`[KEYWORD]` = the styled comment button. Lines marked **Check** need a 2-minute re-check on
posting day.
